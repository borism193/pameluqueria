# Pameluquería — Sitio Web en Astro + Tailwind CSS ✨

Landing page elegante, moderna y minimalista diseñada para **Pameluquería** (Estudio de Estilismo & Coloración de Autor).

## 🎨 Estilo & Características

- **Paleta Elegante & Cálida**: Tonos crema (`#FDFBF7`), arena suave, rosa palo (`#E6CFC6`), dorado champagne (`#B8925A`) y carbón profundo (`#241F1C`).
- **Tipografía Editorial**: *Cormorant Garamond* para títulos y *Plus Jakarta Sans* para lectura ágil.
- **Menú de Servicios Interactivo**: Filtro por categoría (`Coloración & Mechas`, `Cortes & Styling`, `Tratamientos Capilares`, `Eventos & Novias`) con botón **Reservar** en cada servicio que abre WhatsApp con el mensaje pre-armado.
- **Comparador Interactivo Antes / Después**: Control deslizable táctil y con mouse para comparar transformaciones reales.
- **Asistente de Turnos por WhatsApp**: Formulario rápido en la sección de contacto que arma automáticamente el mensaje con nombre, servicio elegido, día y franja horaria.
- **Edición Centralizada**: Todos los textos, precios, fotos, horarios y número de WhatsApp se editan desde un único archivo: `src/data/siteData.ts`.

## 🚀 Cómo ejecutar el proyecto

1. Asegúrate de tener instalado [Node.js](https://nodejs.org/) (versión 18.17.1 o superior).
2. Abre una terminal en la carpeta del proyecto e instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Abre `http://localhost:4321` en tu navegador.
